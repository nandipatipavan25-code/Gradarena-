ATS Semantic Alignment Formula
Dwaani's ATS engine calculates an objective 0–100% match score based on: Technical Skills Overlap (40%) + Project Experience Depth (30%) + Architectural & Domain Fit (20%) + Educational Criteria (10%).

4. Test Evaluation & Real-Time Interview Loop

The core interview engine operates as a concurrent, event-driven loop. Each answer submitted by the candidate is evaluated in real time across three explicit dimensions:

Scoring Dimension Weight Evaluation Focus & Rubric Range
Relevance 33.3% Directly addresses core engineering prompt; penalizes evasive or off-topic responses. 0 – 100%
Accuracy 33.3% Verifies domain correctness, architecture, realistic logic, and correct tooling. 0 – 100%
Clarity 33.3% Assesses structured verbal delivery, conciseness, and professional articulation. 0 – 100%
Parallel Concurrency via ThreadPoolExecutor
When SubmitAnswerView receives an answer, it initiates two worker threads concurrently:
• Thread A: Computes 3D scores and qualitative feedback via ai_service.evaluate_answer().
• Thread B: Synthesizes the next adaptive question via ai_service.generate_next_question().
This slashes overall API turnaround latency by over 55% (down to ~2.8 seconds).

Adaptive Question Difficulty Scaling

  • Score > 85%: Escalates to Senior / Architect questions probing distributed trade-offs, concurrency, and failure recovery.
  • Score 60 – 85%: Asks Intermediate questions examining practical tooling, library choices, and project implementation.
  • Score < 60%: Smoothly pivots ("Let's switch gears...") to Foundational definitions to verify core competencies.
  • Zero Duplication: Actively checks against question_bank to strictly prohibit repetitive inquiries.
  • Non-IT Role Guardrails: Suppresses software coding inquiries for Non-IT JDs (HR, Sales, Operations, Finance).

5. Multi-Layered Proctoring & Malpractice Engine

Dwaani continuously safeguards assessment authenticity:

  • Tab-Switch Detection: Listens to document.visibilitychange; triggers snapshot captures when the candidate navigates away.
  • Dual-Stream Canvas Blending: Simultaneously blends webcam and screen-sharing frames onto an HTML5 canvas and pushes snapshots to LogAnomalyView.
  • Malpractice Abort: If critical cheating thresholds are breached, the session is terminated early, the score is set to 0, and the candidate is flagged as Reject.
